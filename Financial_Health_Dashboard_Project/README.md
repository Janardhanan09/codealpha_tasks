# Financial Health Dashboard

This Power BI dashboard analyzes sample financial data to explore income, expenses, savings, outstanding debt, and credit scores.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Dashboard Features
- Total Income and Total Expenses
- Total Savings and Outstanding Debt
- Average Credit Score and Net Balance
- Monthly Income vs Expenses
- Expenses by Category
- Income by Source
- Savings by Financial Goal
- Interactive slicers for Date, City, and Income Source

## Purpose
This project was developed as part of my CodeAlpha Power BI internship tasks to demonstrate data cleaning, DAX calculations, data visualization, and interactive dashboard development.

**Note:** This project uses sample data for educational and portfolio purposes.
