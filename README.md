\# HR Analytics Dashboard | Power BI



\## Project Overview

This project focuses on analyzing employee data using Microsoft Power BI to understand workforce trends, employee attrition, performance, job satisfaction, and other key HR metrics.



The dashboard transforms raw HR data into meaningful insights that can help HR teams monitor employee-related trends and support data-driven decisions.



\## Project Objectives

\- Analyze active employees and employee attrition.

\- Monitor employee performance, job satisfaction, and work-life balance.

\- Understand salary, training hours, absence days, and monthly working hours.

\- Present key HR metrics through an interactive Power BI dashboard.



\## Tools and Technologies

\- Microsoft Power BI

\- Power Query for data cleaning and transformation

\- DAX (Data Analysis Expressions) for measures and KPIs

\- Microsoft Excel / CSV for source data



\## Key Performance Indicators (KPIs)

\- Active Employee Count

\- Attrition Employee Count

\- Attrition Percentage

\- Average Salary

\- Average Performance Rating

\- Average Job Satisfaction

\- Average Work-Life Balance

\- Average Training Hours

\- Average Absence Days

\- Average Monthly Hours
